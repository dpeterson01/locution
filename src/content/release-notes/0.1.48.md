## Locution 0.1.48

Apple Foundation Models is now the default cleanup on Apple Silicon.

## What's new

- **Apple Foundation Models by default (Apple Silicon, macOS 26+)** — new installs now use Apple's on-device model for cleanup automatically: no API key, no model to choose, nothing leaves your Mac. You can still switch to Ollama or a cloud provider anytime, and if you already picked a provider your choice is kept.
- **A simpler Cleanup Provider panel** — the provider list is alphabetized with Custom at the bottom and now fits without scrolling, and the API Key and Model fields hide when they don't apply (Apple Foundation Models needs neither).

## Requirements

- Apple Silicon Mac on macOS 26 (Tahoe) or newer, with Apple Intelligence enabled, for the on-device provider.
- Ollama stays available for cleanup on any Mac and for longer dictations.
