## Locution 0.1.51

Adds cleanup feedback and makes transcription more reliable when Locution is busy.

## What's new

- **Rate cleanup results from History** - use thumbs up or down to record whether cleanup helped. Rated examples can be exported as JSONL for future improvements.
- **Bad cleanup results no longer replace a good transcript** - Locution falls back to the raw transcript when cleanup returns an empty, malformed, or implausibly expanded result.
- **Hotkey input is preserved while processing** - held push-to-talk and queued toggle input now start when the current transcription finishes instead of being lost.
- **More reliable local transcription** - the transcription runtime has been upgraded, and GPU selections now use stable device identities across restarts and device reordering.
- **Release logs protect dictated text** - production logs no longer include transcript content.

Under the hood, updater signing is aligned with Tauri v2, and validation now covers packaged startup, history migration, portable mode, Rust, browser, and Nix changes.
